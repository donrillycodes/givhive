A unified, warmer
look across the whole product.

The landing page already does the heavy lifting — soft cream surfaces, Fraunces serifs, italic accents, deep-forest green. This mockup brings that same identity to the auth pages, NGO dashboard, and admin tools, fixes the dead-space and alignment issues from your screenshots, and lays out a sharper mobile experience. Nothing here changes functionality — same routes, same data, same API calls.

Component library — one consistent vocabulary.

These are the design tokens and primitives every page reuses. The component APIs stay the same — `<Button variant="primary">`, `<Badge tone="success">`, `<StatCard label value meta icon>` — only the visual treatment changes.

Typography

A unified warm identity.

Body copy uses DM Sans. Headings use Fraunces with optional italic accents — same as the landing page. Eyebrow labels use uppercase, tracked, semi-bold green-700. Mono is reserved for IDs and code.

Note on implementation: the redesign reuses every existing component API — `Button`, `Badge`, `StatCard`, `FormField`, `EmptyState`, `FilterPills`, `Avatar`. Only their internal styles change. Pages keep their hooks (`useQuery`, `useMutation`, `useAuth`), routes, and Firebase / API calls intact.
